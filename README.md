**PROBLEM STATEMENT**
Students use multiple applications to manage project files, tasks, and communication. This creates difficulties such as:
1.Lack of centralized storage.
2.File duplication and data loss.
3.Difficulty in tracking project progress.
4.Poor team coordination.
5.Security and accessibility concerns.

** OBJECTIVES**
1.Provide centralized cloud storage.
2.Improve student collaboration.
3.Enable secure file sharing.
4.Simplify task and project management.
5.Provide scalable cloud infrastructure.
6.Implement AWS cloud computing concepts.

**MAIN FEATURES**
1.**User Login**: Allows students to securely log into the platform.
2.**Project Workspace**: Allows students to create and manage academic projects.
3.**File Upload and Sharing:** Enables students to upload, download, and share project files.
4.**Team Collaboration**: Allows students to invite team members and work together.
5.**Task Management**: Helps students assign and manage project tasks.
6.**Progress Tracking**: Tracks completed and pending project tasks.
7.**Activity Dashboard**: Allows students to view project updates and activity history.

**AWS SERVICES**
1	Amazon EC2:	Hosts and runs the application using Docker containers.
2	Amazon S3:	Stores project files, reports, documents, and source code.
3	Amazon RDS:	Stores user information, project details, and task data.
4	Amazon VPC:	Provides a secure and isolated cloud network.
5	AWS IAM:	Manages access permissions and resource security.
6	Elastic Load Balancing:	Distributes incoming traffic across EC2 instances.
7	EC2 Auto Scaling:	Automatically adjusts computing capacity based on demand.
8	Amazon CloudWatch:	Monitors application performance, logs, metrics, and alarms.

**SYSTEM ARCHITECTURE**
The proposed application follows a multi-tier cloud architecture.
1.Frontend: Provides the student user interface.
2.Backend: Handles application requests and project operations.
3.Amazon EC2: Hosts the application using Docker.
4.Amazon S3: Stores project files and documents.
5.Amazon RDS: Stores user and project information.
6.AWS IAM and VPC: Provide cloud access control and network security.
7.CloudWatch: Monitors application performance.

**BENEFITS**
1.Centralized academic project management.
2.Secure file storage and sharing.
3.Improved communication and teamwork.
4.Reduced file duplication and risk of data loss.
5.Easy task management and progress tracking.
6.Access to project resources from anywhere.
7.Cloud-based accessibility and scalability.

**CONCLUSION**
Our project provides a centralized cloud-based platform to manage student academic projects efficiently. It helps students store and share files, collaborate with team members, manage tasks, and track project progress.

The proposed AWS services support application hosting, secure storage, database management, networking, scalability, and monitoring. This project also provides practical experience in implementing cloud computing concepts using AWS.
